# Defendr

Application de gestion du club CHAD (Cœur d'Hérault Auto Défense) : membres, disciplines, niveaux, saisons et paramètres.

Application web installable sur iPhone (Safari → Partager → Sur l'écran d'accueil). Les données sont stockées dans Supabase (hébergement en France), protégées par connexion et par des règles d'accès : ce dépôt ne contient aucune donnée d'adhérent.
