Installer Defendr

Cet assistant installe votre propre copie de Defendr, vide, avec la base de données de votre club. Comptez 15 minutes, dont 5 d’attente. Faites-le sur un ordinateur.

Avant de commencer : si votre navigateur propose de traduire GitHub ou Supabase, refusez. Gardez cette page ouverte : les liens ci-dessous s’ouvrent dans un nouvel onglet.

1Créer vos deux comptes gratuits

  1. Créez un compte GitHub avec l’e-mail du club : github.com/signup. Choisissez un nom simple, sans espace (ex : club-krav-beziers) : il fera partie de l’adresse du logiciel. Confirmez votre e-mail.
  2. Ouvrez supabase.com et cliquez sur Continue with GitHub. Si Supabase vous demande de créer une organisation : nom du club, type Personal, plan Free. Ne créez pas de projet : l’assistant s’en charge.

2Donner une clé GitHub à l’assistant

  1. Ouvrir la page de création de clé GitHub (connectez-vous si besoin).
  2. Les cases nécessaires sont déjà cochées. À Expiration, choisissez 7 days.
  3. Tout en bas, cliquez sur Generate token, puis copiez la clé (elle commence par ghp_).

3Donner une clé Supabase à l’assistant

  1. Ouvrir la page des clés Supabase
  2. Cliquez sur Generate new token, nommez-la Defendr, validez, puis copiez la clé (elle commence par sbp_).

Les deux clés restent dans votre navigateur et chez GitHub : elles ne sont envoyées à personne d’autre. Vous les supprimerez à la fin.

4Lancer l’installation

Installation en cours

Ne fermez pas cette page. Vous pouvez la laisser dans un coin de l’écran.

    Un clic de votre part : GitHub demande d’autoriser les automatismes de votre copie.
    1. Ouvrez cette page GitHub.
    2. Cliquez sur le bouton vert I understand my workflows, go ahead and enable them.
    3. Revenez ici et cliquez sur « C’est fait ».

    ✓Defendr est installé

    L’adresse du logiciel de votre club :

    1. Ouvrez cette adresse et cliquez sur Créer un compte. Le premier compte créé devient président(e) : faites-le vous-même, maintenant.
    2. Confirmez votre e-mail avec le message reçu (regardez aussi dans les indésirables), puis connectez-vous.
    3. Allez dans Paramètres : coordonnées du club, cotisations, puis créez la saison en cours.
    4. Supprimez les deux clés données à l’assistant, elles ne servent plus : clés GitHub (bouton Delete sur « Installation Defendr ») et clés Supabase (« Defendr »).

    Si la page affiche une erreur 404, attendez 2 minutes et rechargez : GitHub termine la mise en ligne. Sur iPhone : ouvrez l’adresse dans Safari, Partager, puis « Sur l’écran d’accueil ».

    Un problème ? Le guide d’installation manuelle décrit les mêmes étapes, une par une : INSTALLER-NOUVEAU-CLUB.md. Vous pouvez relancer l’assistant autant de fois que nécessaire : ce qui est déjà fait est conservé.
